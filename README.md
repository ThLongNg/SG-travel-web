# Saigon Travel — 日本人旅行者のためのベトナム観光ガイド

> README tạm thời (pha 0). Integrator viết bản đầy đủ ở pha 2.

```bash
npm install
npm run dev -- --host   # mở http://<IP-máy>:4321/dev/glass trên điện thoại cùng Wi-Fi
npm run build
```

- Đặc tả: `docs/SPEC.md` · Kế hoạch: `docs/PLAN.md` · Hợp đồng: `docs/CONTRACT.md`
- **Thay video nền**: đặt file vào `public/media/` với đúng tên `hero-saigon-{mobile,desktop}.{mp4,webm}`, `hero-saigon-poster.webp`, `hero-saigon-poster-portrait.webp`, `hero-saigon-bg.webp` (xem `src/lib/media.ts`). Hiện tại đều là placeholder tự sinh.
